## Task: Refactor Agentic Dev

First, **understand the existing project thoroughly**—its architecture, directory structure, dependencies, agent workflows, API endpoints, configuration, and deployment setup. Then implement the following changes **incrementally, safely, and without breaking existing functionality**.

### Required Updates

1. **TypeScript → JavaScript**
   - Migrate TypeScript files to JavaScript while preserving functionality, component structure, and type-safe runtime behavior where applicable.

2. **LangChain + LangGraph workflow**
   - Use LangChain and LangGraph for the multi-agent workflow.
   - Preserve the workflow: **Analyzer → Planner → Coder → Reviewer → Validator**.
   - Use LangSmith only if useful for tracing, debugging, and observability.

3. **Model Configuration**
   - **Primary:** OpenAI model for reasoning, planning, code generation, and review.
   - **Secondary:** A Groq-supported model as a fallback when the primary model fails or is unavailable.
   - Make provider selection and fallback configurable. Never hardcode API keys.

4. **Configuration & Dependencies**
   - Audit and update `.env.example`, environment-variable loading, `requirements.txt`, and `config.yaml`.
   - Add all missing dependencies, model settings, API keys, agent configurations, and sensible defaults.
   - Remove obsolete dependencies and settings. Keep secrets out of version control.

### Implementation Rules

- **Work sequentially:** Complete one change at a time.
- **Create checkpoints:** After every change, run relevant tests, verify functionality, document results, and create a Git checkpoint before proceeding.
- **Isolate changes:** Keep each update modular and independently testable; avoid unrelated modifications.
- **Use multiple agents where practical:** Delegate independent audits or tasks to separate agents, but coordinate shared-file changes and integrate results carefully.
- **Validate continuously:** Check imports, dependencies, frontend builds, backend startup, agent execution, model fallback, configuration loading, and deployment compatibility.
- **Preserve existing behavior:** Fix regressions and update documentation wherever necessary.

### Expected Outcome

Deliver a working, validated Agentic Dev project with JavaScript, a LangChain/LangGraph workflow, configurable OpenAI and Groq models, and consistent configuration files.

**Start by analyzing the existing codebase.** Present the current architecture, identified issues, and a step-by-step migration plan before modifying files. Then implement each step, verify it, record its checkpoint, and proceed only when the current step passes validation. Report completed changes, test results, remaining issues, and the exact checkpoint for each stage.
